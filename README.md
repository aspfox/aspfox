# AspFox

A production-ready .NET 8 SaaS boilerplate. Skip the authentication plumbing, multi-tenancy setup, and Stripe integration. Ship your product on day one.

---

## How it works

AspFox is delivered as a `dotnet new` template. After purchase
you receive a download link via email. Save the file, run two
commands, and you have a fully renamed compilable codebase with
your project name throughout.

```bash
dotnet new install ./AspFox.Templates.1.0.0.nupkg
dotnet new aspfox -n YourProjectName
```

No GitHub repository access. No fork. No rebase conflicts when
you extend the code.

From there: copy `.env.example` to `.env`, fill in your keys,
run `make up`, and the application is running locally.
Full setup guide at [docs.aspfox.com](https://docs.aspfox.com).

No GitHub repository access required. No fork. No rebase conflicts when you extend the code.

## What's included

**Authentication**  
JWT RS256 with asymmetric keys. 15-minute access tokens, 7-day rotating refresh tokens with reuse detection. Email/password, magic link, Google OAuth, GitHub OAuth. Forgot password, email verification, and full enumeration protection on every auth endpoint.

**Multi-tenancy**  
Row-level isolation enforced by EF Core global query filters — cross-tenant leaks are architecturally prevented, not just guarded by convention. Tenant creation, slug generation, switching without re-authentication, and a complete team invitation flow with 72-hour expiry.

**Role-based access control**  
Three built-in roles (Owner, Admin, Member) with ten granular permission strings. Dynamic ASP.NET Core policy provider — no startup registration per permission. Custom role creation per tenant with configurable permissions.

**Stripe billing**  
Checkout, customer portal, upgrades, downgrades, cancellation scheduling, and reactivation. 14-day free trial on Pro and Business plans. Idempotent webhook processing. Active subscription status cached in Redis. Manual override panel for support use.

**Email — 12 templates**  
Welcome, email verification, password reset, magic link, password changed, invitation, trial expiry (7-day), trial expiry (1-day), payment failed, payment recovered, cancellation scheduled, cancellation confirmed. Shared base layout. Email failures never break auth or billing.

**Background jobs**  
Trial expiry pipeline (7-day warning → 1-day warning → automatic downgrade). Subscription sync with Stripe every 2 hours. Daily token cleanup. Invitation cleanup. Hangfire dashboard secured behind the `is_admin` JWT claim.

**Admin panel**  
User management with search, soft delete, and impersonation. Tenant management with audit log and subscription status. MRR and subscription count metrics. Full impersonation audit trail. Manual subscription override.

**Frontend**  
Complete authentication pages, workspace onboarding, tenant settings with permission-gated controls, member management, billing page with plan grid and trial countdown, profile with email change flow and account deletion, admin dashboard. Concurrent-safe JWT refresh interceptor. Loading, error, and empty states throughout.

**In-app notifications**  
Notification bell with unread count, 30-second polling, mark-as-read and mark-all-as-read. Notifications generated by billing events, membership events, and ownership transfer.

**Command palette**  
Cmd+K / Ctrl+K. Permission-aware. Fuzzy search with keyboard navigation.

**Dark mode**  
System preference detection, manual toggle, persisted across sessions. Tailwind `darkMode: 'class'`.

**Infrastructure**  
Multi-stage Dockerfiles with Alpine base images and non-root users. Production Compose file with memory limits, health checks, and a single nginx ingress. GitHub Actions CI with parallel backend and frontend jobs, `-warnaserror` enforcing zero warnings. Integration tests using TestContainers against a real PostgreSQL instance.
